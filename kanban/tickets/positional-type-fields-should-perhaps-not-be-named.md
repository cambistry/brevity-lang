# Positional type fields should *not* be named

IDEA:

A positional approach is not accessed by field name, but by destructuring. A typed structure is basically an Object, but with constraints.

And if the positional capability is used, one would hope that it would be in the nature of the thing being modeled, and not just a cheap way to avoid dealing with field names.
