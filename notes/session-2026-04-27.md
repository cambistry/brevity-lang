# Session 2026-04-27 — Reactive Singleton DOM Elements

## Feature: `@decl` attrs in element attr blocks

Inline HTML elements can declare their own reactive state using `@decl` inside the attr block:

```brevity
el = <div
  class="reactive"
  @color Text! = "black"
  style={ 'color: ' + @color }
>
  I change color!
</div>
```

`@color` and the `style` reactive closure are lifted into the parent actor. `el` is the HTML.div address — `body.append!(el)` works directly.

## Implementation

Five files changed:

### `src/lexer.js`
- `parseDomElement`: when `@` (or any non-`[a-zA-Z0-9_-:]` char) appears as first attr char, capture entire attr block as `bvBlock` string (depth-aware for `{}`).
- `HTML_CONSTRUCTOR` token creation: propagate `bvBlock` vs `attrs` via spread.

### `src/ast.js`
- Added `anonymousHtmlActor(tag, actorBody, children)` constructor.

### `src/parser.js`
- `parsePrimary` `HTML_CONSTRUCTOR` branch: token-stream swap — tokenize `bvBlock`, call `parseActorBody`, restore, return `AnonymousHtmlActor`.
- `parseReplyFields` `HTML_CONSTRUCTOR` branch: same bvBlock handling (needed for `-> <div ...>` handler body form).

### `index.js` + `src/codegen/browser/brevity.js`
- `liftReactiveElements(ast)`: walks actor constructorBody/initBody/fn bodies; transforms `AnonymousHtmlActor` → `DomConstructor` with `closure_ref` attrs; merges lifted refs/closures into parent actor. Uses `WeakSet` to deduplicate when same node appears in both constructorBody and initBody.
- `synthesizeReactiveElementBodies(ast)`: after `assignClosureAddresses` renames bare functions to `@N`, updates `closure_ref` placeholder names in DomConstructors.
- Pass order: `liftReactiveElements` → `assignClosureAddresses` → `synthesizeReactiveElementBodies`.
- Deep-clone in processNode: copy `type` verbatim (don't recurse) to avoid adding `type: undefined` to plain data objects like `NamedArgsBag.fields`.

## Tests: `__tests__/html/reactive_element.browser.test.js`
- Q1 (wire shape, no browser): 5 tests — closure ref encoding, static text attrs, no-attr case, @decl creates public ref.
- Q2 (browser render): 2 tests — initial style and text content.
- Q3 (external set): 3 tests — `page.send` on `@color` updates DOM style attribute.

## Key bugs fixed during implementation
1. Lexer produced `HTML_CONSTRUCTOR` token without `bvBlock` (always used `el.attrs`).
2. `parseReplyFields` had its own `HTML_CONSTRUCTOR` handler that bypassed bvBlock entirely.
3. `brevity.js` `extract()` didn't call `liftReactiveElements`/`synthesizeReactiveElementBodies`.
4. `constructorBody` and `initBody` share the same `AnonymousHtmlActor` object reference → double-collection of lifted fns → duplicate `@color` validator error. Fixed with `WeakSet`.
5. `processNode` deep-clone added `type: undefined` to plain dict objects (e.g., `NamedArgsBag.fields`) → spurious named arg `type` in validator. Fixed by copying `type` verbatim instead of pre-initializing `out = { type: node.type }`.
